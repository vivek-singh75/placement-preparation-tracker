# DevTrack 🎯

**Placement Preparation & Progress Tracking Platform**

DevTrack is a web-based placement preparation tracker designed to help students organize, monitor, and evaluate their technical interview preparation.

Students can select one or multiple technology tracks, such as MERN Stack and AI/ML, while DSA preparation is available as a common track for everyone.

The platform provides a centralized dashboard where users can update their learning progress, track completed and ongoing topics, monitor weekly preparation activities, and evaluate their overall placement readiness.

🌐 **Live Demo:** [DevTrack](https://vivek-singh75.github.io/placement-preparation-tracker/)

---

## ✨ Features

- **Multiple Technology Tracks:** Select and track preparation in technologies such as MERN Stack, AI/ML, and other available domains.
- **Dedicated DSA Tracking:** Track Data Structures and Algorithms preparation alongside selected technology tracks.
- **Progress Tracking:** Update learning progress and monitor completed, ongoing, and pending topics.
- **Interactive Dashboard:** View your preparation progress through a centralized dashboard.
- **Weekly Topic Tracking:** Monitor weekly learning topics and identify completed and in-progress tasks.
- **Placement Readiness Overview:** Evaluate your overall preparation progress across selected technology tracks and DSA.
- **Personalized Preparation:** Organize your placement preparation according to your selected learning paths.

## ⚙️ How It Works

1. **Select Technology Tracks:** Choose one or more technologies you want to prepare for, such as MERN Stack or AI/ML.
2. **Start DSA Preparation:** Track DSA progress through the common DSA preparation track.
3. **Update Your Progress:** Mark topics as completed, in progress, or pending based on your learning.
4. **Monitor Weekly Goals:** Review your weekly topics and track your learning consistency.
5. **Analyze Your Dashboard:** View your overall preparation progress and technology-wise performance.
6. **Evaluate Placement Readiness:** Understand how much of your selected preparation tracks you have completed.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/vivek-singh75/placement-preparation-tracker.git
   ```

2. Navigate to the project directory:

   ```bash
   cd placement-preparation-tracker
   ```

3. Install the required dependencies:

   ```bash
   npm install
   ```

4. Start the application using the scripts configured in your project.
